# Asset sources

The active food photography was downloaded from Unsplash's image CDN. The original generated illustrations and low-resolution store/phone artwork were retired. Photos illustrate the local sample menu and must be checked against the restaurant's actual dishes before a public launch.

- Burger: https://images.unsplash.com/photo-1568901346375-23c9450c58cd
- Pizza: https://images.unsplash.com/photo-1513104890138-7c749659a591
- Pasta: https://images.unsplash.com/photo-1473093226795-af9932fe5856
- Cake: https://images.unsplash.com/photo-1578985545062-69928b1d9587
- Citrus drink: https://images.unsplash.com/photo-1544145945-f90425340c7e

Source URLs use https://images.unsplash.com/ followed by the CDN asset identifier. Delivery parameters constrain image size and JPEG quality. Refer to https://unsplash.com/license for the license. No new AI images were generated.

The FOOD wordmark, favicon, layout and generic mobile device illustration are rendered from typography, SVG and CSS in this repository. The device screen displays real catalog data. There are no Apple or Google store badges because there are no confirmed native app listings.

Typography: DM Sans and DM Serif Display, provided through Google Fonts with system/Georgia fallbacks. Fonts can be self-hosted for production if desired.
